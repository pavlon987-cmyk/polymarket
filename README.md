# Polymarket Copy-Trader (paper + live)

Веб-приложение (Next.js + PostgreSQL), которое копирует сделки выбранных трейдеров («китов») Polymarket.

## Что умеет
- **Paper / Live режимы.** Paper — виртуальный банк. Live — реальные маркет-ордера через официальный `@polymarket/clob-client`
  (включается только при всех предохранителях, см. ниже).
- **Стратегия на каждого кита**: способ сайзинга (Kelly / фикс / % кэша / пропорционально киту), фильтры цены/объёма/свежести,
  лимиты на категорию и на кита, take-profit / stop-loss по цене, copy-sells (выход вслед за китом), стоп-слова, ИИ-подсказки.
- **Умное копирование (ИИ)**: любой OpenAI-совместимый API (OpenAI, OpenRouter, DeepSeek, Groq, Ollama…). Настраиваются URL, модель,
  ключ, температура, минимальная уверенность и системный промт трейдера. Модель решает COPY/SKIP и множитель размера.
- **Лечение 401/403**: браузерные заголовки, ретраи с бэкоффом, резервный эндпоинт `/activity`, HTTP-прокси и переопределяемые base-URL.
- Авто-цикл внутри сервера (переживает перезапуск), ручной запуск, журнал, статистика по китам, решения ИИ, Telegram-уведомления,
  поиск активных трейдеров, проверка активности адреса, импорт старого `portfolio_improved.json`.

## Live-режим — предохранители (нужны все)
1. Настройки → Режим = **Live** и тумблер «Разрешить реальные сделки».
2. Переменные окружения сервера:
   ```
   LIVE_TRADING_ENABLED=true
   POLYMARKET_PRIVATE_KEY=0x…          # приватный ключ кошелька-подписанта
   POLYMARKET_FUNDER_ADDRESS=0x…       # ваш proxy-кошелёк Polymarket (где USDC)
   POLYMARKET_SIGNATURE_TYPE=2         # 0 = EOA, 1 = Magic/email, 2 = браузерный кошелёк (по умолчанию)
   ```
3. «Лимит банка для live» в настройках — бот не превысит его.

Пока хоть одно условие не выполнено, бот работает как paper и пишет об этом в журнал.

## CLI (обёртка над API сервера)
```
npm run copytrader            # включить авто-цикл и стримить статус
npm run copytrader:once       # один цикл
npm run copytrader:status
npm run copytrader:whales
npm run copytrader:reset
BASE_URL=http://host:3000 npm run copytrader:status
```
